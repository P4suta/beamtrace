# Support

Use [GitHub Discussions](https://github.com/P4suta/beamtrace/discussions/categories/q-a) for setup questions, diagnostic interpretation, and ideas that are not yet confirmed defects.

Use the structured bug form for reproducible defects and the feature form for scoped proposals. Include the BeamTrace version, OTP version, operating system, and a minimal sanitized reproduction. Do not post distribution cookies, tokens, raw captures, customer data, or private node names.

Suspected vulnerabilities belong in a [private security advisory](https://github.com/P4suta/beamtrace/security/advisories/new), as described in [SECURITY.md](SECURITY.md).

This community project does not currently offer a response-time guarantee or private operational support.
